# 版本管理说明

本项目现在已启用标准 Git 版本管理。

轻量版本快照仍然保留，作为 Git 之外的本地压缩备份方案。日常开发、公式调整、页面修改，以 Git 为主。

## Git 位置

当前可用 Git 程序：

```text
D:\DevelopTools\Git\Git\cmd\git.exe
```

由于该路径未进入当前终端 PATH，命令示例统一使用完整路径。

## Git 常用操作

### 查看改动

```powershell
& 'D:\DevelopTools\Git\Git\cmd\git.exe' status
```

### 查看具体差异

```powershell
& 'D:\DevelopTools\Git\Git\cmd\git.exe' diff
```

### 提交当前改动

```powershell
& 'D:\DevelopTools\Git\Git\cmd\git.exe' add .
& 'D:\DevelopTools\Git\Git\cmd\git.exe' commit -m "说明这次改了什么"
```

### 查看历史

```powershell
& 'D:\DevelopTools\Git\Git\cmd\git.exe' log --oneline --decorate -10
```

### 回退到上一个提交

谨慎使用：

```powershell
& 'D:\DevelopTools\Git\Git\cmd\git.exe' reset --hard HEAD~1
```

更安全的方式是先查看日志，确认提交号后再回退。

## 轻量快照

以下内容是备用方案，不替代 Git。

## 管理范围

会纳入版本快照：

- `src/` 核心代码
- `tools/` 工具脚本和操作面板
- `config/` 配置
- `data/` 关键数据和自选股池
- `docs/` 文档
- `tests/` 测试
- `README.md`
- `requirements.txt`
- 启动/版本管理批处理文件

默认排除：

- `outputs/` 每日报告和导出结果
- `__pycache__/`
- `.versions/`
- `.git/`
- 日志和临时缓存

排除规则在 `.versionignore` 中维护。

## 常用操作

### 创建快照

双击：

```text
创建版本快照.bat
```

或执行：

```powershell
& 'D:\DevelopTools\Python\Python310\python.exe' tools\version_manager.py snapshot -m "说明这次改了什么"
```

### 查看历史

双击：

```text
查看版本历史.bat
```

或执行：

```powershell
& 'D:\DevelopTools\Python\Python310\python.exe' tools\version_manager.py list
```

### 查看当前改动

双击：

```text
查看版本状态.bat
```

或执行：

```powershell
& 'D:\DevelopTools\Python\Python310\python.exe' tools\version_manager.py status
```

### 恢复版本

先查看版本历史，找到版本号，例如 `20260811_153000`，再执行：

```powershell
& 'D:\DevelopTools\Python\Python310\python.exe' tools\version_manager.py restore 20260811_153000 --yes
```

恢复前系统会自动再创建一个备份快照，避免误恢复后无法回头。

## 使用建议

每次做这些操作前，先创建快照：

- 改公式
- 改选股逻辑
- 改操作面板
- 改候选股评分
- 大批量修改数据或配置

建议快照说明写清楚，例如：

```text
砖型图公式改为原始 STICKLINE 口径
```

后续如果安装 Git，可以把当前轻量快照迁移为标准 Git 仓库。
